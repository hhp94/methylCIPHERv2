# methylCIPHERv2: Calculate Epigenetic Clocks

Calculates scores for CpG-based epigenetic clocks to support
hypothesis-driven evaluation and research. A single function scores
every supported clock from a beta matrix of DNA methylation values.
Scoring runs on the local machine, and most clock weights are bundled
with the package. The larger weight sets are downloaded on request.
